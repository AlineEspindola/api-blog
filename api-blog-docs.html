api-blog

API REST para gerenciamento de artigos de blog com suporte a rascunhos, publicação, arquivamento e comentários encadeados.

Base URL http://localhost:3000
Formato JSON
Runtime Node.js + Express 5
Banco PostgreSQL / Memória
Como rodar
Dois modos disponíveis: com banco ou em memória
Modo memória (sem banco, ideal para testes)
# instalar dependências
npm install

# subir em memória
USE_MEMORY_REPO=true npm run dev

Modo PostgreSQL
# configurar variáveis
cp .env.example .env

# criar banco e rodar schema
psql -U postgres -c "CREATE DATABASE api_blog;"
psql -U postgres -d api_blog -f schema.sql

# subir servidor
npm run dev

Variáveis de ambiente (.env)
PORT=3000

DB_HOST=localhost
DB_PORT=5432
DB_NAME=api_blog
DB_USER=postgres
DB_PASSWORD=sua_senha

# "true" para rodar sem banco
USE_MEMORY_REPO=false

HTTP Response
←
serialize()

Domain Classes
←
ArticleRecord

ℹ
O ArticleProxy é o único componente que traduz registros do banco (planos) para objetos de domínio ricos (DraftArticle, PublishedArticle, etc.). As classes de domínio nunca são modificadas.

archived

⚠
Transições inválidas (ex: publicar um artigo já publicado) retornam 422 Unprocessable Entity com a mensagem de erro do domínio.

  "content": "..."

⚠
Só funciona se o artigo estiver no estado published.

Schemas
Formatos de objetos retornados pela API
Article
{
  "id":         string    // UUID gerado automaticamente
  "title":      string    // título do artigo
  "content":    string    // conteúdo do artigo
  "status":     "draft" | "published" | "archived"
  "lastEdited": string    // ISO 8601 datetime
  "comments"?:  Comment[] // presente apenas em GET /comments
}

Comment
{
  "content":  string     // texto do comentário
  "children": Comment[]  // respostas (CommentReplied no domínio)
}
Tratamento de erros
Todos os erros seguem o mesmo formato
Formato de erro
{ "error": "Mensagem descritiva do problema" }

CódigoSituaçãoExemplo
200 Sucesso com corpo Busca, atualização, transição de estado
201 Criado com sucesso POST /articles, POST /comments
204 Sucesso sem corpo DELETE /articles/:id
400 Campos obrigatórios ausentes "authorId, title e content são obrigatórios."
404 Recurso não encontrado "Artigo não encontrado."
422 Regra de domínio violada "This article is already published."
500 Erro interno do servidor "Erro interno do servidor."
